# Общий разбор референсов (способ 2: анализ HTML/CSS)

Данные собраны скриптом по 16 сайтам: статус, стек, шрифты, палитра, радиусы,
H1/H2-структура, формы. Это «дизайн по коду» — композицию и фото не оценивали.
Полный сырой сигнал: `design-signals.json` (см. сессию), ссылки — `links.md`.

## Что общего у всех/большинства

### 1. Рецептура свежести (то же ядро, что в ТЗ на «Кварту»)
- `rassvet.pmlx.ru` — «обжарка по вторникам, отправка в течение суток», H1 «Свежая обжарка с доставкой за два дня» → прямой аналог «жарим по четвергам, привозим в пятницу».
- `randcoffeeroastery.com` — «roasted daily · shipped within 48 hours».
- `nicoscoffeeroastery.com` — H1 «Roasted to order» (не жарим, пока не заказали).
- `unat.coffee` — «обжариваем после подтверждения выпуска».
- `sbmrne.ru` — «ежемесячно 1-2 числа обжариваем, 3-6 числа отправляем».
- Формула всех: **ритм обжарки + срок доставки = доверие**. Свежесть продают цифрами и расписанием, а не эпитетами.

### 2. Структура секций (типовой ордер)
1. Герой: H1 — обещание, а не название компании («Roasted to order», «Свежая обжарка с доставкой за два дня», «Новые лоты. В удобном ритме»).
2. Ассортимент с ценами (карточки 250 г / от-цены).
3. «Как это работает» — нумерованные шаги: unat `01-04`, rand `No 01-05`, sbmrne `1-5`.
4. Подписка как отдельный блок/страница (у всех, кто вообще про подписку).
5. Соцдоказательства: отзывы/FAQ/партнёры (transcend, cathedral, tastycoffee, boldbean).
6. Контакты + форма/CTA.

### 3. Палитра
- Тёплые нейтральные фоны-«крем»: nico `#fff8ec`, rand `#ebe5d8/#f5f0e6`, estate `#edede3`, unat `#f5f4ec`, rassvet `#f1f2f6`.
- Тёмный текст вместо чистого чёрного: `#1c1b19` (nico), `#172014` (unat), `#111` (estate), `#212121` (smallbatch).
- Ровно **один яркий акцент**: coffee-store `#ef5619`, cathedral `#c4293d`, smallbatch `#d12328`, rand `#e40014`, embassy `#fbc88c` на navy `#203351`, unat `#b9ef73`, rassvet `#b8ff00`.
- Общий приём: не «премиальный глянец» (чёрное+золото), а натуральная палитра +1 сигнал цвета.

### 4. Типографика — два кластера
- Гротески-одиночки: Open Sans (kcr), Inter (coffeep, nico), Poppins (coffee-store), Figtree (transcend), Onest (unat), DIN Pro/Gotham (tastycoffee).
- Пара «дисплейный + рабочий» (выглядит менее сгенерированно): **Fraunces + JetBrains Mono** (rand), **Fraunces + Inter + Caveat(рукописный)** (nico), **Instrument Sans + Jost** (cathedral), **Ardeco(дисплей) + базовый** (embassy), **PT-Root/TT-Blues** (estate).
- Капс+леттерспейс в заголовках — приём корпоративных (tastycoffee, embassy), у тёплых брендов — смешанный регистр.

### 5. Формы
- Телефонное поле реально есть только у `coffee-store.by` и `estatecoffee.ru`; у остальных RU — JS-попапы («Заказать звонок», «Получить прайс»).
- Юрчекбокс «согласие на обработку ПД» — обязательный у всех RU; у EN почти нет.
- У EN-референсов форма = подписка на рассылку/корзина, не заявка. Заявочная модель — целиком из RU-сегмента.

### 6. Технический слой
- Мобильный viewport и og:image есть у всех; preloader — у embassy.
- Радиусы: мягкие 8–20px стали нормой (sorso 16-20, nico 16, unat 8, smallbatch 15), но «нерабочий глянец» ловится на 0px (estate, tastycoffee, transcend). Креативный вариант: асимметрия `50% 50% 14px` (unat).

## Чем отличаются

| Ось | Полюса |
|---|---|
| Модель | Корзина/каталог (kcr, coffee-store, sorso, transcend) — витрина-заявка (estate, coffeep, tastycoffee) — подписка-лендинг (unat, cathedral, boldbean) |
| Плотность | Плотные (sbmrne 13k знаков, transcend 11.5k, sorso 9k) ↔ воздух (cathedral 2.3k, rassvet 2.5k, nico 2.8k, rand 3.4k) |
| Тональность | Тёплая ручная (unat, nico, rand) ↔ холодный B2B-корпоратив (tastycoffee, sbmrne) ↔ ресторан-гламур (embassy) |
| Стек | Tilda (unat, estate), Astro/Next (rassvet, rand), Shopify (6 EN), WordPress+Divi+Woo (kcr, coffee-store), Bitrix (sorso, sbmrne) |
| Шаблонность | Самые «шаблонные» по коду: kcr.by (Divi + типовой WooCommerce), sorso.by (Аспро-пресет). Самые самодельные: rand, nico, unat, rassvet |

## Выводы для лендинга «Кварта»
1. H1 = расписание+свежесть («Жарим по четвергам — в пятницу у вас»), не «Добро пожаловать».
2. 6–8 секций по ордеру из п.2, шаги подписки нумеровать.
3. Палитра: кремовый фон + тёмно-коричневый текст + 1 акцент (избегать красного `#d12328/#ef5619` — он у половины референсов).
4. Шрифтовая пара «дисплейный + гротеск», рукописный акцент допустим (как Caveat у nico).
5. Форма: телефонное поле + ПД-чекбокс (по образцу estate/coffee-store), без корзины — модель заявки из RU-сегмента.
6. Чего не делать: Divi/Аспро-плотность, КАПС-корпоратив, чёрное+золото «премиум».

## Ограничение способа 2
Не оценены: реальные фото/иллюстрации, сетка и вертикальный ритм, анимации,
мобильная раскладка. Для этих выводов нужны скриншоты (способ 1).
